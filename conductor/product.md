# Product Overview: `xitdb-odin`

`xitdb-odin` is a pure-Odin implementation of [`xitdb`](https://github.com/xit-vcs/xitdb), an embeddable, immutable, append-only database with persistent structural sharing.

## Reference Repositories
Local clones of the upstream reference implementations are stored in `.tmp/ref/`:
- `.tmp/ref/xitdb-zig` — Canonical Zig implementation (`github.com/xit-vcs/xitdb`)
- `.tmp/ref/xitdb-go` — Reference Go port (`github.com/xit-vcs/xitdb-go`)
